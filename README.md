**[House Price Prediction in Depok — Machine Learning & Streamlit](https://github.com/zakyilhamf647586-spec/UAS-Machine-Learning-Prediksi-Harga-Rumah-Depok)**

- Explored and cleaned housing data, reducing 24,561 records to 19,619.
- Compared **Linear Regression** and **Random Forest Regression**.
- Evaluated model performance using **MAE** and **R²**.
- Built an interactive **Streamlit** application for price estimation.
